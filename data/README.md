# Data

No waveform data are stored in this repository. Synthetic data are regenerated by the code from the seeds recorded in
the preregistration log. The real data used by Task R0, exploration C16 and the prepared Task 2M come from public
repositories and are downloaded with the commands below; their SHA-256 checksums are in `checksums/`, and every
script that reads them was frozen together with those checksums.

## Ridgecrest 2019 (Task R0)

One continuous hour, 2019-07-04 19:00-20:00 UTC, of the CI network (Southern California Seismic Network) with the SCSN
analyst catalogue (102 events, M 1.49-4.50). Source: repository `benchflow-ai/skillsbench` (Apache-2.0), commit
`9a1f4dd5f7659f75707435da3ce854b6e48321d1`, folder `tasks/earthquake-phase-association/`. Original data: Caltech/USGS
Southern California Seismic Network; cite SCEDC when publishing.

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/benchflow-ai/skillsbench.git
cd skillsbench && git sparse-checkout set tasks/earthquake-phase-association
mkdir -p ../realdata/skillsbench_eqassoc
cp tasks/earthquake-phase-association/environment/data/wave.mseed \
   tasks/earthquake-phase-association/environment/data/stations.csv \
   tasks/earthquake-phase-association/verifier/catalog.csv ../realdata/skillsbench_eqassoc/
cd ../realdata/skillsbench_eqassoc && sha256sum -c ../../data/checksums/ridgecrest_2019_R0.sha256
```

The code expects the files in `/home/claude/realdata/skillsbench_eqassoc/` (constant `DATA` in `code/r0/r0_lib.py`);
change that constant for another location.

## Alto Tiberina, Italy (exploration C16 and Task 2M)

Continuous three-component data of the INGV network IV (Alto Tiberina Near Fault Observatory), decimated to 25 Hz, from
the repository `avuan/PyMPA37` (GPL-3.0), commit `4a14b134afec3c1f527b738ca3bae4cdc7cbbbf6`, folder
`main.pympa.dir/24h/`: 2010-07-23 (14 stations; C16) and 2010-02-10, 2010-02-11, 2010-02-12 and 2010-12-31 (Task 2M),
with the station inventory `inv.IV`, `stations.list` and the TABOO catalogue `templates.zmap`. Original data: INGV;
cite the network and the PyMPA authors when publishing.

```bash
git clone --filter=blob:none --sparse https://github.com/avuan/PyMPA37.git
cd PyMPA37 && git checkout 4a14b134afec3c1f527b738ca3bae4cdc7cbbbf6
git sparse-checkout set main.pympa.dir/24h input.calculate_ttimes.dir input.download_data.dir
cd .. && mkdir -p realdata/pympa37_altotiberina_100723 realdata/pympa37_days
cp PyMPA37/main.pympa.dir/24h/100723.* PyMPA37/main.pympa.dir/200.100723.cat PyMPA37/main.pympa.dir/templates.zmap \
   PyMPA37/LICENSE PyMPA37/input.calculate_ttimes.dir/inv.IV PyMPA37/input.calculate_ttimes.dir/aquila_kato.tvel \
   PyMPA37/input.download_data.dir/stations.list realdata/pympa37_altotiberina_100723/
for f in $(awk '{print $2}' data/checksums/altotiberina_other_days_task2M.sha256); do
  cp PyMPA37/main.pympa.dir/24h/$f realdata/pympa37_days/; done
(cd realdata/pympa37_altotiberina_100723 && sha256sum -c ../../data/checksums/altotiberina_20100723_C16.sha256)
(cd realdata/pympa37_days && sha256sum -c ../../data/checksums/altotiberina_other_days_task2M.sha256)
cp data/checksums/altotiberina_other_days_task2M.sha256 realdata/pympa37_days.sha256
```

The catalogue used is `main.pympa.dir/templates.zmap`; the copies of `templates.zmap` in the `input.*` folders of
PyMPA37 are a different file. C16 expects the day 2010-07-23 in `/home/claude/realdata/pympa37_altotiberina_100723/`
and Task 2M the other days in `/home/claude/realdata/pympa37_days/`, with the list of checksums of the latter at
`/home/claude/realdata/pympa37_days.sha256` (it is part of the Task 2M freeze).

## Hi-net swarm (Task R1)

Fukushima-Yamagata swarm of 2 September 2012, 33 min 20 s of continuous three-component data at seven Hi-net
stations, with 14 JMA events (`catalog.dat`), from `Geolab-USTC/MatchLocate2`, commit
`bac5ccb00816a4ec0aaab215ea1c342c730d412f`, folder `example/` (the repository is under GPL-3.0; the waveforms are NIED Hi-net data, subject to the NIED terms of use). Its waveforms were held out until Task R1 (registered on 17 October 2026), which used them once; they are no
longer unseen data.

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/Geolab-USTC/MatchLocate2.git
cd MatchLocate2 && git checkout bac5ccb00816a4ec0aaab215ea1c342c730d412f && git sparse-checkout set example
cd example && sha256sum -c <repository>/data/checksums/hinet_matchlocate2_example.sha256
```

The R1 code reads the data from `/home/claude/realdata/MatchLocate2/example` (`DATA` in `code/r1/r1_lib.py`); move the
clone there or change that constant. The PyOcto velocity model of R1 is built on first use by `hyb_comp.pyocto_1d` from
the JMA2001 points into `code/r1/pyocto_jma2001.model`.

## Pickers and associators

PhaseNet: original model of `AI4EPS/PhaseNet`, commit `62005c6195638f88d077f8870ea895971062715a`
(`model/190703-214543`), run with TensorFlow-CPU 2.15.1 installed apart from the system packages (see the docstring of
`code/real_picker.py`). GaMMA: `AI4EPS/GaMMA`, commit `80394dd4a4c29450da599f507916ecf1db6203dd`, cloned into
`code/gamma_src/` (not included here). PyOcto 0.2.0 and QuakeMigrate from PyPI.
