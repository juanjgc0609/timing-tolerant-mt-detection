# Data cards

One card per dataset (protocol, Section 2): source and version, checksums, catalogue, partitions and the record of
every use. A dataset used for evaluation once is development data from then on. Download commands are in
`data/README.md`.

| Card | Dataset | Status |
|:--|:--|:--|
| `ridgecrest_2019.md` | Ridgecrest 2019, one hour, CI network | development only (used by R0 and C18) |
| `altotiberina_2010.md` | Alto Tiberina 2010, five noise days, IV network | development only (used by C16 and 2M) |
| `hinet_swarm_2012.md` | Hi-net swarm 2012, seven stations | development only (used by R1) |
| `../reserved/README.md` | Reserved confirmatory sequences (Geysers 2024, Antelope Valley 2021, spare Bodie 2020, Colombia slot) | sealed until phase 6 (T3.R4) |

Licences and redistribution terms of every dataset: `LICENCES.md` (T3.R7).
