1. VERDICT
----------

Rule 2B (MT-FW+SC - MT-FW-FREE+SC >= 0.05 at both caps in >= 2 of 3 cells, both seeds), point estimates:

  thin    seed 2024: 2/3 cells, seed 7331: 2/3 cells  -> MET (at the minimum; the one-sided 8-station cell
          fails in both seeds)
  strong  seed 2024: 3/3 cells, seed 7331: 3/3 cells  -> MET

Preregistered interpretation: 2B holds in both regimes, so the 2A gain is NOT attributed solely to pick-free
migration with deflation; within the same solver the radiation operator adds >= 0.05 recall at both caps in
most cells. Qualifications in section 6: the thin verdict is fragile, and the identity ablation removes the
whole operator (signed pattern, polarisation and amplitude geometry), not only the sign.


2. DESIGN AS IMPLEMENTED
------------------------

Windows, networks, catalogues, station corrections. For each seed (2024, 7331), regime (thin, strong), cell
(ladder_4, ladder_6, unilateral_c40) and network (0-4), task2b_ablation.py rebuilds everything with
task2a_confirm's own functions, which it imports rather than copies: net_setup, network, catalogue_real with
seeds [s, 2003, ci, j, ri], estimate_station_corrections, window_rngs, generate_window, matched,
certified_fw_record and task1x_mtglrt.radiation_operator / basis. The windows consume only rng, rng_m and
rng_h (window_rngs[:3]). The picker, degrade_y (rng_d) and the node map (rng_n) that run_job also calls do not
touch those streams, so skipping them reproduces the window sequence exactly. The number of windows is
20 per network, 100 per cell, 1200 in total.

MT-FW+SC is the stored 2A record (task2a_parts, identical to the 2A JSON). MT-FW-FREE+SC uses the same call,
certified_fw_record(STA, MF/sd, default_grid(), DEFAULT_TAUS, Gs, Qs, truth, tcorr=corr), with the defaults
kmax 5, min_sep 5 km and CAPV 6 (task1x_mtglrt.CAPV, used in node_vectors). The only change is
Gs = Qs = [I] * 675 nodes, where I = eye(2*ns*3). Shapes checked: v is (31, 2, ns, 3), vf = v.reshape(31, -1)
is (31, 6ns) in (phase, station, component) order, G is (6ns, 6), I is (6ns, 6ns), and
(I @ vf).reshape(2, ns, 3) == v exactly. The statistic is ||vt||^2 / 2, half the total capped peak-vector
energy. It is sign-invariant, m = lstsq(I, vf) = vf, and the deflation subtracts the observed peak vectors
convolved with the matched-filter autocorrelation.

Endpoint and statistics (analyze_2b.py), as in analyze_2a.py:
- Recall at <= 0.1 and <= 0.25 realised false events per window on the exact FROC (froc_exact.exact_HF),
  with the operating point chosen on the evaluation itself.
- The rule uses point estimates with the threshold 0.05 - 1e-9.
- Paired window bootstrap: 2000 replicates, default_rng([s, ci, ri]). These are the same resamples as
  analyze_2a.py, so the 2A-b intervals in Table 4 of analyze_2b_out.txt reproduce analyze_2a_out.txt exactly.
- Additional reading: network bootstrap, 2000 replicates, 5 networks drawn with replacement,
  default_rng([s, ci, 77]) as in verif_2a/cluster_boot_verif.py.
- The operating point, and the maximum over comparators, are re-chosen in every replicate.
- The window pairing between the 2A and 2B JSON is asserted: k, network, truth, origin times and the
  MT-FW+SC records are all identical.

Compute: 60 network jobs, 8 s each on average (495 s CPU in total), 2 workers.


3. CONTROLS
-----------

Selfcheck (task2b_selfcheck.txt; seed 2024, thin, ladder_6, net 0, window 0, 1 source, 6 stations).
(a) Over all 675 x 31 hypotheses, the FREE score equals ||vt||^2/2 to a relative 6.8e-16. The first FREE
    record score (73.9898) equals the maximum of ||vt||^2/2 over all hypotheses (relative 1.9e-16).
(b) The score is unchanged, bit for bit, when one station's vector changes sign.
(c) I lstsq(I, vf) - vf = 0 exactly.
(d) Flipping the sign of the waveform of any one of the 6 stations leaves the FREE records bit-identical
    (6/6) and changes the MT-FW+SC records (6/6). In the unflipped window MT-FW+SC misses the event and FREE
    detects it, which shows the ablation is not trivially weaker window by window.

Per-network control (all 60 networks, recorded in every part file and asserted again in analyze_2b.py):
- STA, statics, number of catalogue draws, catalogue locations and origins, and station corrections are
  bit-identical to task2a_parts (60/60).
- Truth and origin times are identical in 1200/1200 windows.
- MT-FW+SC recomputed on windows 0 and 1 of every network equals the stored records EXACTLY (120/120
  windows).
- Certified FREE equals dense FREE (dense_fw_record_c) exactly (120/120).

Incident (first attempt, log2b_attempt1.txt, task2b_control_failed_attempt1.txt). The first run stopped on a
control failure, as required. 32 networks had passed. The 7331 ladder_6 networks produced in the resumed 2A
sessions failed: MT-FW+SC scores differed in the last 1-2 digits (relative <= 6e-15, identical hits and
order), and in one network one correction differed by 8.9e-16 s.

Cause: numpy's OpenBLAS (DYNAMIC_ARCH) selects the Prescott kernel on this machine by default. The 18
networks that 2A wrote in its resumed seed-7331 sessions (after 23:30) were produced with the AVX-512
(SkylakeX) kernel:
- 7331 strong ladder_6 net 2-4
- 7331 thin ladder_6 net 0-4
- 7331 ladder_4, both regimes

Verified: with OPENBLAS_CORETYPE=SkylakeX the corrections and records of these networks reproduce bit for
bit, and with Prescott they do not. Haswell, Sandybridge and Zen do not reproduce them either. The other 42
networks reproduce bit for bit with the default kernel.

The final run (run_queue_2b.sh, log2b.txt) therefore ran those 18 networks with OPENBLAS_CORETYPE=SkylakeX and
the rest with the default kernel. Every network then passed the unchanged, exact control. The kernel is
recorded in each new part file. The 32 parts from the first attempt carry no field, but they ran with the
default kernel. No threshold or tolerance was relaxed.

Kernel sensitivity (exploratory, task2b_kernel_check.py, task2b_kernel_check.txt). The 18 affected networks
were recomputed with the default kernel, all 20 windows each:
- MT-FW+SC: every record differs at relative <= 6e-15, with no change of hits or order in any window.
- MT-FW-FREE+SC: the records diverge in later Frank-Wolfe steps in some windows (score differences up to
  17 percent, from near-equal candidates flipping under rounding). Hits or order change in only 2 of 360
  windows.
- Recall at 0.1 and 0.25 is identical for both methods in all 4 affected cells.
- Exact ties of the FREE maximum are rare. At the first step, in 60 sampled windows, 0 ties in ladder_6
  and 1 tie in 20 windows in unilateral_c40, the tied nodes sharing the same epicentre.
Consequence for 2A: its per-network results mix two BLAS kernels, and the effect on MT-FW is at rounding
level only.

5. WHAT THE RESULTS SAY
-----------------------

(i) Strong clutter: the radiation operator carries the 2A result. MT-FW+SC beats FREE by +0.06 to +0.35 in all
6 cell-seed pairs. FREE is at the level of the best 2A comparator (QuakeMigrate), within -0.08 to +0.08, and
below WAVE-PT@20. Without the operator, the pick-free solver with deflation and SC does not beat the state of
the art in strong clutter. The rule holds in 97-98 percent of bootstrap replicates.

(ii) Thin clutter: mixed.
- The operator helps clearly in the 4-station cells of both seeds, with the network-bootstrap intervals above
  0 at 0.25.
- In the 6-station cells the gain is positive but uncertain. For 2024 the intervals include 0 in both
  bootstraps.
- In the one-sided 8-station cell FREE equals MT-FW+SC in both seeds (-0.01/-0.01 and +0.04/+0.05).
- The rule passes at its minimum (2/3 in each seed) and would hold in only about 60 percent of bootstrap
  replicates.
- A large part of the thin-clutter 2A advantage over QuakeMigrate needs no radiation pattern. FREE alone
  beats the best comparator by +0.10 to +0.34 at cap 0.25 in 5 of 6 cell-seed pairs (all except 4 st. 2024,
  at -0.01). In those cells the gain over QuakeMigrate comes mainly from pick-free migration
  with deflation and SC.

(iii) Scope of the ablation. Replacing G by the identity removes the whole physical operator:
- the signed double-couple pattern across stations;
- the polarisation constraint (P along the ray, S in the transverse plane);
- the 1/d and P/S amplitude geometry.
2B therefore establishes that the operator matters. It does not isolate the sign, which was the audit's
question.

The comparison with WAVE-PT@20, which is sign-free but polarisation-constrained, suggests that polarisation
is a substantial part of the operator's value in strong clutter, where clutter transients are randomly
polarised. In strong clutter FREE is 0.01 to 0.23 below WAVE-PT@20 even though WAVE-PT@20 has no deflation
and no SC.

2A-b, the other-node subspace, keeps the dimension but scrambles geometry and polarisation together, so it
does not isolate the sign either. Separating the sign from the polarisation would need a further ablation
that is not preregistered: for example, free amplitude along the ray for P and in the transverse plane for S,
i.e. Q = the block-diagonal ray projectors, called "FREE-PT". Any such run must be declared exploratory.

Wording for the proposal, per the preregistration: 2B holds in both regimes, so the gain is attributed to
the radiation operator within the solver, not solely to pick-free migration with deflation. It should add
that:
- in thin clutter the attribution is marginal (2 of 3 cells per seed, with no gain in the one-sided
  8-station cell);
- in thin clutter most of the advantage over QuakeMigrate survives without the operator (at cap 0.25);
- the ablation does not separate the sign of the pattern from the polarisation constraint.


6. LIMITATIONS
--------------

L1. Five networks per cell. The per-window intervals ignore clustering, and the network bootstrap with 5
    clusters is coarse. Several individual cells have intervals that include 0 even where the point estimate
    passes (thin 6 st. both seeds; strong 4 st. 7331 at 0.1; strong one-sided 8 2024 in the network
    bootstrap).
L2. The rule is decided on point estimates, as preregistered. Thin passes at the minimum count.
L3. The operating point is chosen on the evaluation itself for both methods, as in 2A. This is symmetric.
L4. FREE inherits the MT-FW solver choices (CAPV 6 per station and phase, 5 km exclusion, kmax 5, deflation
    with the matched-filter autocorrelation), which were tuned with the moment-tensor statistic. A retuned
    energy detector might do somewhat better. The preregistered ablation deliberately keeps the solver fixed.
L5. The BLAS kernel is a process-level numerical setting. It was matched per network to reproduce 2A exactly,
    and it does not change any recall value (section 3).
